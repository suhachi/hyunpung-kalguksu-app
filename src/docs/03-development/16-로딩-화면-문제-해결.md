## 🔍 문제 진단

### 근본 원인 (2개 발견)

#### 1. **Tailwind CSS Import 누락** ⚠️ 중요

**영향**: 모든 Tailwind 클래스가 적용되지 않아 레이아웃 깨짐

#### 2. **Next.js 패키지 사용** ⚠️ 중요
**파일**: `/components/ui/sonner.tsx`  
**문제**: `next-themes` 패키지를 사용하고 있지만 Vite 프로젝트임  
**영향**: 런타임 에러 발생, React 렌더링 중단

## ✅ 해결 방법

### 1. Tailwind CSS Import 추가

**파일**: `/styles/globals.css`

```diff
+ @import "tailwindcss";
+ 
  @custom-variant dark (&:is(.dark *));
  
  :root {
    --font-size: 16px;
```

**이유**:
- Tailwind CSS 4.0부터 `@import "tailwindcss"` 필수
- 이전 버전의 `@tailwind base;` 등��� 사용 안 함
- 이것 없이는 모든 Tailwind 유틸리티 클래스가 작동하지 않음

## 📊 문제 발생 원인 분석

### 왜 이런 문제가 발생했는가?

1. **Tailwind 4.0 마이그레이션 미완료**
   - Tailwind 4.0은 새로운 CSS 레이어 시스템 사용
   - `@import "tailwindcss"` 없이는 아무것도 작동하지 않음
   - 기존 프로젝트에서 복사할 때 누락된 것으로 추정

2. **Shadcn UI 템플릿 복사**
   - Shadcn UI는 Next.js 기본 템플릿 제공
   - sonner.tsx가 Next.js 버전 그대로 복사됨
   - Vite 환경에 맞게 수정 필요했음

## 🔄 Tailwind CSS 4.0 마이그레이션 가이드

### 변경 사항 요약

| Tailwind 3.x | Tailwind 4.0 |
|-------------|--------------|
| `@tailwind base;`<br>`@tailwind components;`<br>`@tailwind utilities;` | `@import "tailwindcss";` |
| `tailwind.config.js` 필수 | `tailwind.config.js` 선택 |
| PostCSS 설정 필요 | Vite 플러그인 불필요 |
| `@layer` 사용 | `@theme inline` 사용 |

### 현재 프로젝트 구조

```css
/* globals.css */
@import "tailwindcss";  /* ⭐ 필수! */

@custom-variant dark (&:is(.dark *));

:root {
  /* CSS 변수 정의 */
}

@theme inline {
  /* Tailwind 테마 커스터마이징 */
}

/* 글로벌 스타일 */
body { ... }
```
