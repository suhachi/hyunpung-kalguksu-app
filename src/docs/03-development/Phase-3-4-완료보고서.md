## 🔄 데이터 플로우

### 리뷰 작성 플로우
```
리뷰 작성 → 유효성 검사 → 사진 업로드 
→ Firestore/localStorage 저장 
→ 포인트 적립 (200P or 100P)
→ 사진 리뷰 쿠폰 발급 (3,000원)
→ 성공 알림 → 주문 페이지로 이동
```

### 리뷰 관리 플로우
```
관리자 대시보드 → 리뷰 목록 조회 
→ 필터/정렬 적용 
→ 답글 작성 → Firestore 업데이트 
→ 실시간 UI 반영
```

### 리뷰 신고 플로우
```
고객/관리자 → 리뷰 신고 
→ 신고 사유 선택 
→ reportReview API 호출 
→ 신고 카운트 증가 
→ 관리자 알림
```
