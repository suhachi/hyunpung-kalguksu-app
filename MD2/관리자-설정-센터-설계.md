## 개요

### 목적

`/admin/settings` 경로에 **설정 센터**를 구현하여:
- API 키 및 설정의 **상태 진단** 제공
- 서버 비밀키의 **안전한 입력 가이드** 제공
- CLI 명령 생성 및 복사 기능
- .env 템플릿 다운로드
- 배포 스크립트 제공

### 주요 기능

- ✅ 5개 탭 네비게이션 (결제/배달/지도/알림/운영)
- ✅ 상태 진단 패널 (Functions 연결, 키 존재 여부, 헬스체크)
- ✅ CLI 명령 생성 및 복사
- ✅ .env 템플릿 다운로드
- ✅ 배포 스크립트 제공
- ✅ 비밀키는 저장하지 않음 (CLI 생성용으로만 사용)

## 보안 원칙

### 핵심 원칙

1. **서버 비밀키는 `functions:config`에만 저장**
   - 클라이언트에 절대 노출 금지
   - UI에서는 "설정됨/미설정" 상태만 표시
   - 입력한 키 값은 저장하지 않고 CLI 명령 생성용으로만 사용

2. **클라이언트 공개 키는 `.env.local`에 저장**
   - VAPID Key, Kakao/Google Maps API Key 등
   - 템플릿 다운로드 제공

3. **관리자 전용 접근**
   - `/admin/settings`는 `owner` 또는 `admin` 역할만 접근 가능
   - UI에 Role 배지 표시

4. **헬스체크는 Callable Function으로 구현**
   - `adminHealthCheck` Function은 관리자만 호출 가능
   - `functions:config` 상태는 클라이언트에서 직접 조회 불가

## UI 설계

### 레이아웃

각 탭은 **2열 그리드** 구조:
- **좌측**: 상태 진단 패널
- **우측**: 설정/가이드 패널

### 상태 패널 (공통)

**상태 항목 예시**:
- ✅ Functions 연결: Connected/Not set
- ✅ 필수 키 존재 여부: Set/Missing
- ✅ 라우팅/웹훅 헬스체크: OK/Fail (에러 메시지)
- ✅ .env 템플릿 검증: Valid/Invalid

**배지 색상**:
- 초록색: 정상 (Connected, Set, Configured)
- 빨간색: 오류 (Not set, Missing, Not configured)
- 노란색: 경고 (Not supported)

### 설정/가이드 패널

#### 1. 결제 탭 (PaymentTab)
- API Endpoint 입력 (저장 안 함)
- MID 입력 (저장 안 함)
- API Key 입력 (저장 안 함, password 타입)
- Return URL, Cancel URL 입력
- **CLI 명령 미리보기** (실시간 업데이트)
- **CLI 복사** 버튼
- **확인 명령** 버튼 (`firebase functions:config:get`)

#### 2. 배달 탭 (DeliveryTab)
- Webhook Secret 입력 (저장 안 함)
- 허용 IP 목록 입력
- CLI 명령 미리보기 및 복사
- **배달 설정** (비밀 아님, Firestore 저장):
  - 최대 배달 거리 (km)
  - 야간 할증 (원)

#### 3. 지도 탭 (MapsTab)
- Kakao Maps API Key 입력 (저장 안 함)
- Google Maps API Key 입력 (저장 안 함)
- **.env 템플릿 다운로드** 버튼

#### 4. FCM 탭 (FCMTab)
- VAPID Key 입력 (저장 안 함)
- 브라우저 지원 확인
- 알림 권한 상태 확인
- 알림 권한 요청 버튼
- **.env 템플릿 다운로드** 버튼

#### 5. 운영 탭 (OperationsTab)
- Firestore 연결 상태
- Storage 연결 상태
- CORS 설정 확인
- Functions 연결 상태
- **진단 실행** 버튼
- **배포 스크립트 복사** 버튼

## 구현 상세

### 1. 헬스체크 Function

**파일**: `src/functions/src/admin/health.ts`

```typescript
export const adminHealthCheck = functions.https.onCall(async (data, context) => {
  // 인증 및 관리자 권한 확인
  if (!context.auth || !isAdmin(context.auth.uid)) {
    throw new functions.https.HttpsError('permission-denied', '관리자만 접근 가능');
  }

  const config = functions.config();
  
  return {
    functions: {
      connected: true,
      nicepay: {
        endpoint: !!config.nicepay?.endpoint,
        mid: !!config.nicepay?.mid,
        key: !!config.nicepay?.key,
      },
      delivery: {
        secret: !!config.delivery?.secret,
      },
    },
    // ...
  };
});
```

### 2. CLI 명령 생성

**파일**: `src/lib/admin/adminSettings.api.ts`

```typescript
export function generateNicepayCLI(params: {
  endpoint: string;
  mid: string;
  key: string;
  returnUrl: string;
  cancelUrl: string;
}): string {
  return `firebase functions:config:set nicepay.endpoint="${params.endpoint}" nicepay.mid="${params.mid}" nicepay.key="${params.key}" nicepay.return_url="${params.returnUrl}" nicepay.cancel_url="${params.cancelUrl}"`;
}
```

### 3. 상태 진단 패널

각 탭의 상태 패널은 `health` prop을 받아 상태 배지를 표시:

```typescript
<StatusBadge label="Functions" status={status.functions} />
<StatusBadge label="NICEPAY" status={status.nicepay} />
```

### 4. 접근 제어

```typescript
if (!userRole || (userRole !== 'owner' && userRole !== 'admin')) {
  return <AccessDenied />;
}
```
