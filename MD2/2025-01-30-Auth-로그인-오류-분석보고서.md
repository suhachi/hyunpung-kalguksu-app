# Auth 로그인 오류 분석 보고서 (auth/invalid-credential)

작성일: 2025-01-30  
프로젝트: 현풍닭칼국수 PWA 배달앱  
증상: Firebase: Error (auth/invalid-credential)

---

## 1) 요약
- 현상: 이메일/비밀번호 로그인 시 `auth/invalid-credential` 발생
- 성격: 최신 Firebase Web SDK에서 “계정 없음/비밀번호 불일치” 등 다수를 하나의 오류로 통합 보고
- 영향: 관리자 진입 불가, 설정 센터 점검 흐름 차단

## 2) 주요 원인 후보
1. 계정/비밀번호 불일치 또는 계정 Disabled
2. Email/Password 프로바이더 미활성화
3. Authorized domains 미등록(현재 접속 도메인 불일치)
4. 프론트 `.env`가 다른 프로젝트를 가리킴(API 키/프로젝트 ID 불일치)
5. 브라우저 로컬 캐시(IndexedDB/LocalStorage)에 남은 이전 프로젝트 토큰 충돌

## 3) 5분 즉시 진단 절차
1) 사용자/상태 확인
- Console → Authentication → Users → `admin@hp-kal.com` 존재·Disabled=false
- 필요 시 Reset password → `test1234`

2) Sign-in method
- Console → Authentication → Sign-in method → Email/Password = Enabled

3) Authorized domains
- Console → Authentication → Settings → Authorized domains
- `localhost`, `127.0.0.1`, `hp-kal.web.app`, `hp-kal.firebaseapp.com` 등록

4) 프로젝트 일치(.env)
- `.env(.local)`이 hp-kal 설정인지 확인
- 브라우저 콘솔: `getApp().options.projectId === 'hp-kal'`

5) 네트워크 응답 확인
- DevTools → Network → `accounts:signInWithPassword` → `error.message`
  - `INVALID_LOGIN_CREDENTIALS` → 계정/비번 이슈 유력
  - `USER_DISABLED` → 계정 활성화 필요
  - `TOO_MANY_ATTEMPTS_TRY_LATER` → 지연 후 재시도

## 4) 추가 교차검증(REST)
```bash
curl -X POST \
  'https://identitytoolkit.googleapis.com/v1/accounts:signInWithPassword?key=<API_KEY>' \
  -H 'Content-Type: application/json' \
  -d '{ "email":"admin@hp-kal.com", "password":"test1234", "returnSecureToken": true }'
```
- 성공 시 프론트 설정/도메인/캐시 문제 가능성↑
- 동일 오류 시 계정/비번/프로바이더/도메인 문제 가능성↑

## 5) 수정/완화 조치
- 계정 재설정: `admin@hp-kal.com` 비번 `test1234`로 재설정
- 프로바이더: Email/Password 활성화
- 도메인: 허용 도메인 4종 등록
- .env 교정: hp-kal 프로젝트 값으로 통일, 콘솔에서 projectId 일치 검증
- 캐시 정리: 로그아웃 → 앱 탭 종료 → Application → IndexedDB(LocalStorage) 초기화 후 재시도

## 6) 프론트 방어 코드 권장
```ts
try {
  await signInWithEmailAndPassword(auth, email.trim(), password);
} catch (e: any) {
  console.warn(e.code, e.message);
  toast.error('이메일 또는 비밀번호를 확인해주세요.');
}
```

## 7) 상태/후속
- 관리자 온보딩을 위해 임시 `adminSetup` 함수 배포(토큰 보호) → owner 승격 자동화
- 계약 후: Secret Manager 전환 및 운영 키 세팅, 설정 센터 배지 초록 확인

## 8) 체크리스트(DoD)
- [ ] Email/Password Enabled
- [ ] Authorized domains 4종 등록
- [ ] 관리자 계정 존재·활성, 비번 재설정 완료
- [ ] .env 프로젝트=hp-kal 확인, 브라우저 projectId 일치
- [ ] 캐시 초기화 후 로그인 성공
