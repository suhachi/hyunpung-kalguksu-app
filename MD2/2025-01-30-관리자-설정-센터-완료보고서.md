## 구현 범위

### 1. 탭 구조

```
/admin/settings
├── 결제 탭 (PaymentTab)
├── 배달 탭 (DeliveryTab)
├── 지도/지오코딩 탭 (MapsTab)
├── 알림/FCM 탭 (FCMTab)
└── 운영/보안 탭 (OperationsTab)
```

**접근 권한**: `owner` 또는 `admin` 역할만 접근 가능

### 2. 비밀키 처리 원칙

#### 서버 비밀키 (functions:config)
- NICEPAY: `endpoint`, `mid`, `key`, `return_url`, `cancel_url`
- 배달대행사: `delivery.secret`, `delivery.allowed_ips`

**처리 방식**:
- ✅ UI에서 입력 값 저장하지 않음
- ✅ CLI 명령 생성용으로만 사용
- ✅ 상태 배지로 "설정됨/미설정"만 표시
- ✅ CLI 복사 버튼 제공

#### 클라이언트 공개 키 (.env.local)
- FCM VAPID Key
- Kakao Maps API Key
- Google Maps API Key
- Firebase 설정 값들

**처리 방식**:
- ✅ .env 템플릿 다운로드 제공
- ✅ 템플릿에는 모든 필수 필드 포함

### 3. 헬스체크 항목

#### Functions 연결
- `functions:config` 접근 가능 여부
- NICEPAY 설정 존재 여부 (endpoint, mid, key)
- 배달대행사 Webhook Secret 존재 여부

#### FCM
- 브라우저 지원 여부 (`Notification`, `PushManager`)
- VAPID Key 설정 여부
- 알림 권한 상태 (`granted`/`denied`/`default`)

#### 지도 API
- Kakao Maps API Key 존재 여부
- Google Maps API Key 존재 여부

#### 운영 환경
- Firestore 연결 확인
- Storage 연결 확인
- CORS 설정 확인 (프리플라이트 OK)
- Functions 연결 확인

### 4. 운영 스크립트

**배포 순서** (복사 버튼 제공):
```bash
# 1. Firestore 인덱스 및 규칙
firebase deploy --only firestore:indexes,firestore:rules

# 2. Storage Rules
firebase deploy --only storage

# 3. Functions
firebase deploy --only functions

# 4. Frontend 빌드 및 Hosting
npm run build
firebase deploy --only hosting
```

### 5. Firestore 저장 구조

**컬렉션**: `adminSettings/core`

**저장 항목** (비밀 아님):
```typescript
{
  delivery: {
    maxDistanceKm: number;        // 최대 배달 거리
    feeTable: Array<{             // 배달비 구간표
      toKm: number;
      fee: number;
    }>;
    nightSurcharge: number;       // 야간 할증
    weightFees: {                 // 무게 할증
      light: number;
      normal: number;
      heavy: number;
    };
  },
  notifications: {
    orderUpdates: boolean;        // 주문 알림
    marketing: boolean;            // 마케팅 알림
    promotions: boolean;          // 프로모션 알림
  },
  operations: {
    maintenanceMode: boolean;    // 점검 모드
    allowPickup: boolean;         // 픽업 허용
    allowDelivery: boolean;       // 배달 허용
    minOrderAmount: {             // 최소 주문 금액
      delivery: number;
      pickup: number;
    };
  }
}
```

**비밀키는 저장하지 않음**: 서버 비밀키는 `functions:config`에만 저장

### 상태 배지
