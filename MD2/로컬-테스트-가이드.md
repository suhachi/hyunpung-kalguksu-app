## 🧪 테스트 절차

### 1. 관리자 로그인
**방법 1**: 브라우저 콘솔에서 실행
```javascript
localStorage.setItem('mockRole', 'owner');
location.reload();
```

**방법 2**: URL에 파라미터 추가
```
http://localhost:3000/admin/menus?role=admin
```

### 2. 메뉴 수정 화면 접근
1. 관리자 대시보드 접속: `/admin/menus`
2. 수정할 메뉴 선택
3. "수정" 버튼 클릭

### 3. 이미지 업로드
1. 메뉴 수정 다이얼로그에서 "메뉴 이미지" 파일 선택
2. 이미지 파일 선택 (JPG, PNG 등)
3. "저장" 버튼 클릭

### 4. 확인 사항

#### 브라우저 Network 탭
- ✅ **OPTIONS 요청** → Status: 200 OK
- ✅ **PUT/POST 요청** → Status: 200 OK
  - URL: `https://firebasestorage.googleapis.com/v0/b/hp-kal.firebasestorage.app/o/...`

#### Firebase Console 확인
1. [Firebase Console](https://console.firebase.google.com/project/hp-kal/storage) 접속
2. Storage > Files 탭
3. `menus/{menuId}/{timestamp}.webp` 파일 확인

#### UI 확인
- 화면 새로고침 후 새 이미지 즉시 반영 확인
- 이전 이미지가 삭제되었는지 확인

## 🔍 문제 해결

### 문제: 업로드 실패 (CORS 오류)
**해결**:
- CORS 설정 확인: `gcloud storage buckets describe gs://hp-kal.firebasestorage.app --format="default(cors_config)"`
- `http://localhost:3000` 또는 `http://localhost:5173`이 origin에 포함되어 있는지 확인

### 문제: 인증 오류 (Permission denied)
**해결**:
- 관리자 권한 확인: `localStorage.setItem('mockRole', 'owner')`
- URL에 `?role=admin` 추가

### 문제: Firebase 초기화 오류
**해결**:
- `.env` 파일 확인
- 개발 서버 재시작: `npm run dev`
