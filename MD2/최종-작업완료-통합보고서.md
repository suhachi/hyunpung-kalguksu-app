## 🎯 해결된 문제들

### 문제 1: CORS 오류 ✅ 해결
- **증상**: `Access to XMLHttpRequest blocked by CORS policy`
- **해결**: `cors.json` 생성 후 Firebase Storage 버킷에 적용

### 문제 2: 버킷 이름 불일치 ✅ 해결
- **증상**: `bucket not found` 오류
- **해결**: `src/lib/firebase.ts`에서 명시적으로 `gs://hp-kal.firebasestorage.app` 지정

### 문제 3: Storage Unauthorized 오류 ✅ 해결
- **증상**: `storage/unauthorized` 오류
- **해결**: Firebase Auth 로그인 구현 및 Firestore 사용자 문서 생성

### 문제 4: 저장 버튼 멈춤 ✅ 해결
- **증상**: 이미지 변경 후 저장 버튼이 "저장 중..." 상태 멈춤
- **해결**: 에러 처리 개선 및 상태 리셋 로직 추가

### 문제 5: 모달 투명 문제 ✅ 해결
- **증상**: 메뉴 수정/시간제 설정 다이얼로그 배경 투명
- **해결**: `DialogContent`에 `bg-white` 클래스 추가
