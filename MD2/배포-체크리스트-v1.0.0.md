## 📋 배포 순서

### 1단계: 브랜치 푸시

```bash
# 원격 푸시 (인증 필요 시 PAT 사용)
git checkout feat/admin-settings-center
git push -u origin feat/admin-settings-center

# release/v1.0.0에 머지
git checkout release/v1.0.0
git pull origin release/v1.0.0
git merge feat/admin-settings-center --no-ff -m "Merge admin settings center"
git push origin release/v1.0.0
```

### 2단계: PR 생성

- GitHub에서 `release/v1.0.0` → `main` PR 생성
- PR 본문: `MD2/PR-템플릿-v1.0.0.md` 사용
- 라벨: `release`, `report`, `qa-check`

### 3단계: Firebase Functions Config 설정

#### NICEPAY 설정

```bash
firebase functions:config:set \
  nicepay.endpoint="https://sandbox-api.nicepay.co.kr" \
  nicepay.mid="YOUR_MID" \
  nicepay.key="YOUR_KEY" \
  nicepay.return_url="https://your-project.web.app/pay/return" \
  nicepay.cancel_url="https://your-project.web.app/pay/cancel"
```

#### 배달대행사 Webhook 설정

```bash
firebase functions:config:set \
  delivery.secret="YOUR_WEBHOOK_SECRET" \
  delivery.allowed_ips="1.2.3.4,5.6.7.8"
```

#### 설정 확인

```bash
firebase functions:config:get
```

### 4단계: Firebase 배포 (순서 중요!)

```bash
# 1. Firestore 인덱스 및 규칙
firebase deploy --only firestore:indexes,firestore:rules

# 2. Storage Rules
firebase deploy --only storage

# 3. Functions (리전 고정: asia-northeast3)
firebase deploy --only functions --region=asia-northeast3

# 4. Frontend 빌드 및 Hosting
npm run build
firebase deploy --only hosting
```

**참고**: `firebase.json`에 `functions.region: "asia-northeast3"` 설정 시 `--region` 플래그 생략 가능

### 5단계: 프로덕션 스모크 테스트

#### 스모크 6/6

1. ✅ 로그인/인증
2. ✅ 메뉴 이미지 업로드
3. ✅ 장바구니 → 체크아웃
4. ✅ 결제 플로우 (Mock)
5. ✅ 주문 내역 조회
6. ✅ 관리자 대시보드 접근

#### 헬스체크 (설정 센터)

1. `/admin/settings` 접속
2. 각 탭 상태 배지 확인:
   - **결제 탭**: Functions 연결, Endpoint, MID, Key → 모두 `Set`
   - **배달 탭**: Functions 연결, Webhook Secret → 모두 `Set`
   - **지도 탭**: Kakao/Google Maps API → `Set` (설정 시)
   - **FCM 탭**: VAPID Key, 브라우저 지원, 알림 권한 → 모두 `Set`/`Supported`/`Granted`
   - **운영 탭**: Firestore, Storage, CORS, Functions → 모두 `Connected`/`OK`

3. CLI 복사 → 설정 반영 후 새로고침으로 배지 갱신 확인
4. FCM 권한/Service Worker 확인
5. Storage CORS 프리플라이트 OK 체크

## 문제 해결

### GitHub 인증 오류

```bash
# PAT (Personal Access Token) 사용
git remote set-url origin https://YOUR_TOKEN@github.com/suhachi/hyunpung-kalguksu-app.git
```

### Functions Config 설정 오류

```bash
# 설정 초기화 (필요 시)
firebase functions:config:unset nicepay
firebase functions:config:unset delivery

# 재설정
firebase functions:config:set nicepay.endpoint="..." ...

# 설정 확인
firebase functions:config:get
```

### Functions 리전 확인

```bash
# Functions 리전 확인
firebase functions:list

# 특정 리전에 배포 확인
firebase deploy --only functions --region=asia-northeast3
```

### Firestore TTL 설정

```javascript
// Firestore Console에서 TTL 필드 설정 또는 Functions로 초기화
// idempotency_keys 컬렉션에 'expiresAt' 필드 추가
// deliveryEvents 컬렉션에 'expiresAt' 필드 추가

// 예시: Functions에서 초기화 스크립트
const admin = require('firebase-admin');
admin.firestore().collection('idempotency_keys').doc('example').set({
  key: 'example',
  expiresAt: admin.firestore.Timestamp.fromDate(
    new Date(Date.now() + 7 * 24 * 60 * 60 * 1000) // 7일 후
  ),
});
```

### App Check 설정

```bash
# 개발 환경: Debug Token 발급
# Firebase Console → App Check → Apps → Debug Token 확인

# 운영 환경: reCAPTCHA v3
# Firebase Console → App Check → Apps → reCAPTCHA v3 활성화
```

### Cloud Scheduler 설정

```bash
# Cloud Scheduler API 활성화
gcloud services enable cloudscheduler.googleapis.com

# Functions 리전과 동일하게 설정 (asia-northeast3)
# Cloud Console에서 스케줄 잡 생성 시 리전 선택
```

### 배포 실패

```bash
# 로그 확인
firebase functions:log

# 특정 Function만 재배포
firebase deploy --only functions:adminHealthCheck
```
