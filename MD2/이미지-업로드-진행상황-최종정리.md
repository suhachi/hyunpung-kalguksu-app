## 🔧 해결된 문제들

### 문제 1: CORS 오류 ✅ 해결
- **증상**: `Access to XMLHttpRequest blocked by CORS policy`
- **원인**: Firebase Storage 버킷에 CORS 설정 미적용
- **해결**: `cors.json` 생성 후 버킷에 적용

### 문제 2: 버킷 이름 불일치 ✅ 해결
- **증상**: `bucket not found` 오류
- **원인**: `.env`에 `hp-kal.appspot.com` 설정, 실제 버킷은 `hp-kal.firebasestorage.app`
- **해결**: `src/lib/firebase.ts`에서 명시적으로 `gs://hp-kal.firebasestorage.app` 지정

### 문제 3: Storage Unauthorized 오류 ✅ 해결
- **증상**: `storage/unauthorized` 오류
- **원인**: Mock 인증 사용으로 Firebase Auth 토큰 없음
- **해결**: 
  - Firebase Auth 로그인 페이지 구현
  - 보호 라우트 컴포넌트 추가
  - Firestore에 사용자 문서 생성

### 문제 4: 저장 버튼 "저장 중..." 상태 멈춤 ✅ 해결
- **증상**: 이미지 변경 후 저장 버튼이 계속 "저장 중..." 상태
- **원인**: 
  - 에러 발생 시 상태 리셋 없음
  - `onSave` 호출 실패 처리 미흡
- **해결**:
  - `finally` 블록에서 `setSaving(false)` 보장
  - 에러 재전파 (`throw error`)
  - `toast` 알림 추가

### 문제 5: 모달 투명 문제 ✅ 해결
- **증상**: 메뉴 수정/시간제 설정 다이얼로그 배경 투명
- **원인**: `DialogContent`에 배경색 클래스 누락
- **해결**: `bg-white` 클래스 추가
