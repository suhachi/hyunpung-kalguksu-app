## 1) 배포 개요
- 목적: 관리자 설정 센터 포함 7대 핵심 기능 배포 및 안정화 가드 적용
- 범위: Firestore 인덱스/규칙, Storage Rules, Cloud Functions, Hosting
- 결과: Functions/Rules/Hosting 배포 성공, 가드 상태에서 안전 동작 확인

## 2) 주요 변경/조치
- Functions 리전/리소스 표준화
  - asia-northeast3(서울) 적용: deliveryWebhook, adminHealthCheck, 이미지 파이프라인
  - 런타임: Node.js 20로 상향 (firebase.json, functions/package.json)
- 빌드 이슈 해결
  - 배달 타입 로컬화: `src/functions/src/delivery/types.ts` 추가 및 import 정리
  - sharp 사용 교정: default import, `file.save({ metadata })`로 저장 메타데이터 지정
  - 누락된 `./payments/nicepay` 참조 제거(향후 비밀키 설정 후 복원 예정)
- 설정/가드
  - functions:config 현재 비어 있음 `{}` → 결제/웹훅 503 가드로 안전 차단
  - 관리자 설정 센터에서 “계약 진행 중” 상태 표시(프런트 가드)

## 3) 실행 로그(요약)
- Firestore/Storage 규칙 배포: 완료
- Functions 배포: 완료
