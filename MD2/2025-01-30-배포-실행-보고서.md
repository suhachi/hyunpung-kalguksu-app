## 2) Functions 설정/리전
- `firebase.json`에 `functions.region = asia-northeast3` 설정 완료
- 리소스 설정 적용:
  - `deliveryWebhook`: timeout 30s, memory 256MB, concurrency 10
  - `adminHealthCheck`: timeout 10s, memory 256MB
  - `onMenuImageFinalize`: timeout 300s, memory 1GB

## 3) Functions Config (서버 비밀키)
- 현재 상태: `firebase functions:config:get` 결과 비어 있음 `{}`
- 필요 설정:
  - NICEPAY: `nicepay.endpoint, nicepay.mid, nicepay.key, nicepay.return_url, nicepay.cancel_url`
  - Delivery Webhook: `delivery.secret, delivery.allowed_ips`

## 4) 배포 순서
1. `firebase deploy --only firestore:indexes,firestore:rules`
2. `firebase deploy --only storage`
3. `firebase deploy --only functions --region=asia-northeast3`
4. `npm run build && firebase deploy --only hosting`

## 5) 스모크/헬스체크 (관리자 설정 센터)
- 각 탭 배지 Set/OK 확인: 결제/배달/지도/FCM/운영

- NICEPAY `return_url`/`cancel_url` 실제 호스트와 정확히 일치 검증
- `firebase functions:list`로 리전 asia-northeast3 확인
