# v1.0.0 Release Notes

**릴리즈 일자**: 2025-01-30  
**버전**: v1.0.0  
**상태**: ✅ Production Ready

## ✨ New Features

### 1. 결제 시스템 (NICEPAY)

- **NICEPAY 승인/환불/망취소** 통합
  - Firebase Functions에서 NICEPAY API 연동
  - 결제 인증 요청 (`createPayment`)
  - 결제 승인 (`approvePayment`)
  - 결제 취소/부분 취소 (`cancelPayment`)
  - 환불 처리 (`refundPayment`)
- **Idempotency 키 관리**
  - 중복 결제 방지
  - 동일 요청에 대한 일관된 응답 반환
- **보안 강화**
  - HMAC-SHA256 서명 검증
  - 결제 금액 일치 검증

### 2. 쿠폰 시스템

- **쿠폰 적용/검증**
  - 체크아웃 페이지 쿠폰 UI 컴포넌트
  - 실시간 쿠폰 검색 및 필터링
  - 최소 주문 금액 검증
  - 만료일 검증
  - 중복 사용 방지
- **주문 시 쿠폰 스냅샷 저장**
  - 쿠폰 정보를 주문 문서에 불변 스냅샷으로 저장
  - 쿠폰 변경 후에도 주문 시점의 쿠폰 정보 보존

### 3. 거리 기반 배달비

- **구간별 배달비 계산**
  - 0-1km: 3,000원
  - 1-3km: 4,000원
  - 3-5km: 5,000원
- **추가 할증**
  - 야간 할증 (22:00 ~ 06:00): +1,000원
  - 무게 할증 지원
- **배달 불가 지역 UX**
  - 블랙리스트 지역 자동 차단
  - 최대 배달 거리 제한 (5km)
  - 사용자 친화적인 오류 메시지
- **주소 입력 UI**
  - 주소 검색 및 Geocoding
  - 실시간 배달비 계산 표시

### 4. 주문 관리

- **주문 내역 조회**
  - 주문 목록 페이지 (필터링, 무한 스크롤)
  - 상태별 필터 (pending, accepted, preparing, completed, canceled)
  - 날짜 범위 필터
- **주문 상세 페이지**
  - 주문 정보, 메뉴, 결제 정보 표시
  - 배달/픽업 정보 표시
- **재주문 기능**
  - 이전 주문을 장바구니에 자동 추가
  - 가격 변경 시 경고
  - 품절 항목 차단

### 5. 이미지 파이프라인

- **자동 이미지 최적화**
  - WebP 포맷 변환
  - 썸네일 생성 (640px)
  - 리사이즈 이미지 생성 (1200px)
- **Firebase Functions 트리거**
  - 메뉴 이미지 업로드 시 자동 처리
  - `onMenuImageFinalize` 트리거
- **Cache-Control 설정**
  - 1년 캐시 유지로 성능 최적화
- **Storage Rules 강화**
  - 파일 크기 제한 (5MB)
  - MIME 타입 검증 (`image/*`)
  - 원본/썸네일/리사이즈 파일은 Functions만 생성

### 6. FCM 주문상태 알림

- **실시간 푸시 알림**
  - 주문 상태 변경 시 자동 알림 전송
  - Firebase Functions 트리거 (`onOrderUpdated`)
- **딥링크 지원**
  - 알림 클릭 시 해당 주문 상세 페이지로 자동 이동
- **알림 인박스**
  - 모든 알림을 목록으로 확인
  - 읽음/삭제 기능
  - 타입별 아이콘 및 필터링
- **브라우저 알림 통합**
  - 포그라운드 메시지 리스너
  - Toast 알림 표시

### 7. 배달관제 시스템

- **Provider 어댑터 패턴**
  - Mock Provider (개발/테스트용)
  - Provider A (실제 배달대행사 API)
  - Custom Provider (직접 설정)
- **Webhook 통합**
  - Firebase Functions Webhook 엔드포인트
  - HMAC-SHA256 서명 검증
  - Idempotency 처리 (중복 이벤트 방지)
- **실시간 배달 추적**
  - Firestore 실시간 구독 (`useDeliveryTasks` 훅)
  - 배달 상태 자동 업데이트
  - GPS 좌표 추적
- **관리자 관제 UI**
  - 배달 현황 실시간 모니터링
  - 통계 대시보드 (전체/진행중/완료/SLA 지연)
  - 배달 취소 기능
  - SLA 지연 알림 (45분 초과)

## 🔐 Security / Rules

### Storage Rules 강화
- 파일 경로 스코프 제한 (`menus/{menuId}/`)
- MIME 타입 검증 (`image/*`)
- 파일 크기 제한 (5MB)
- `orig_*`, `thumb_*`, `resized_*` 파일은 Functions만 생성

### Firestore Rules 강화
- `deliveryTasks`: 관리자 읽기, Functions만 쓰기
- `deliveryEvents`: 관리자 읽기, Functions만 쓰기
- `idempotency_keys`: Functions만 읽기/쓰기

### 비밀키 분리
- 환경 변수로 관리 (`.env.local`, `functions:config`)
- 프로덕션 환경에서 안전하게 관리

## ⚙️ Config

### Frontend 환경 변수 (`.env.local`)

```bash
# Firebase 설정
VITE_FIREBASE_API_KEY=...
VITE_FIREBASE_AUTH_DOMAIN=...
VITE_FIREBASE_PROJECT_ID=...
VITE_FIREBASE_STORAGE_BUCKET=...
VITE_FIREBASE_MESSAGING_SENDER_ID=...
VITE_FIREBASE_APP_ID=...
VITE_FIREBASE_MEASUREMENT_ID=...

# FCM (선택사항)
VITE_FIREBASE_VAPID_KEY=...

# 기능 플래그
VITE_USE_FIREBASE=true
VITE_DELIVERY_ENABLED=true
VITE_DELIVERY_PROVIDER=mock  # mock | providerA | custom

# 배달대행사 API (Provider A)
VITE_DELIVERYA_BASE_URL=...
VITE_DELIVERYA_API_KEY=...
VITE_DELIVERYA_PUBLIC_KEY=...

# Geocoding API (선택사항)
VITE_KAKAO_MAPS_API_KEY=...
VITE_GOOGLE_MAPS_API_KEY=...
```

### Firebase Functions 환경 변수

```bash
# NICEPAY 설정
firebase functions:config:set nicepay.endpoint="..." nicepay.mid="..." nicepay.key="..." nicepay.return_url="..." nicepay.cancel_url="..."

# 배달대행사 Webhook
firebase functions:config:set delivery.secret="..." delivery.allowed_ips="..."
```

## ✅ Deploy Steps

### 1. Firestore 인덱스 및 규칙 배포

```bash
firebase deploy --only firestore:indexes,firestore:rules
```

### 2. Storage Rules 배포

```bash
firebase deploy --only storage
```

### 3. Functions 배포

```bash
firebase deploy --only functions
```

### 4. Frontend 빌드 및 Hosting 배포

```bash
npm run build
firebase deploy --only hosting
```
