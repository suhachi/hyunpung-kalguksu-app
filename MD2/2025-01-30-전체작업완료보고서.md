## 기술 스택 및 아키텍처

### Frontend
- **Framework**: React 18 + TypeScript
- **Routing**: React Router v6
- **UI Components**: shadcn/ui + Tailwind CSS
- **State Management**: React Context API
- **Form Handling**: React Hook Form
- **Icons**: lucide-react
- **Notifications**: sonner (Toast)

### Backend (Firebase)
- **Database**: Firestore (NoSQL)
- **Storage**: Firebase Storage
- **Functions**: Firebase Cloud Functions (Node.js 18)
- **Authentication**: Firebase Auth
- **Messaging**: Firebase Cloud Messaging (FCM)
- **Analytics**: Firebase Analytics

### 외부 서비스
- **결제**: NICEPAY API
- **배달대행사**: Pluggable Provider System (Mock/Provider A)
- **Geocoding**: Kakao Maps API / Google Maps API (Mock 지원)

### 개발 도구
- **Package Manager**: npm / yarn
- **Build Tool**: Vite
- **Linting**: ESLint
- **Type Checking**: TypeScript (strict mode)

## 기능별 상세 구현 내용

### A) 결제 승인/망취소/환불 (NICEPAY)

#### 구현 내용
- Firebase Functions에서 NICEPAY API 연동
- Idempotency 키 관리 (중복 결제 방지)
- 서명 검증 (HMAC-SHA256)
- 결제 금액 일치 검증
- 4가지 결제 함수 구현:
  - `createPayment`: 결제 인증 요청
  - `approvePayment`: 결제 승인
  - `cancelPayment`: 결제 취소/부분 취소
  - `refundPayment`: 환불 처리

#### 주요 파일
- `src/functions/src/payments/nicepay.ts`: 결제 Functions
- `src/functions/src/common/idempotency.ts`: Idempotency 관리
- `src/functions/src/common/signature.ts`: 서명 검증
- `src/lib/functions.ts`: 클라이언트 래퍼

#### 특징
- ✅ Idempotency 키로 중복 결제 방지
- ✅ 서명 검증으로 보안 강화
- ✅ 금액 일치 검증
- ✅ 상세한 에러 처리 및 로깅

## Firestore 구조

### 컬렉션 구조

```
firestore/
├── orders/                    # 주문
│   └── {orderId}/
│       ├── orderId: string
│       ├── userId: string
│       ├── status: OrderStatus
│       ├── couponSnapshot?: {...}
│       ├── deliveryTaskId?: string
│       └── ...
│
├── deliveryTasks/             # 배달 태스크
│   └── {taskId}/
│       ├── orderId: string
│       ├── driverId: string
│       ├── status: DeliveryStatus
│       ├── eta: number
│       ├── lastCoord?: Coordinates
│       └── ...
│
├── deliveryEvents/            # Webhook 이벤트 로그 (Idempotency)
│   └── {eventId}/
│       ├── taskId: string
│       ├── type: WebhookEventType
│       ├── timestamp: number
│       └── ...
│
├── notifications/             # 알림 기록
│   └── {notificationId}/
│       ├── userId: string
│       ├── type: NotificationType
│       ├── title: string
│       ├── body: string
│       ├── deepLink?: string
│       ├── read: boolean
│       └── ...
│
├── idempotency_keys/         # Idempotency 키 (결제/Webhook)
│   └── {key}/
│       ├── key: string
│       ├── createdAt: Timestamp
│       ├── expiresAt: Timestamp
│       └── response: any
│
└── users/                    # 사용자
    └── {uid}/
        ├── role: 'admin' | 'owner' | 'user'
        ├── meta/
        │   └── fcm/          # FCM 토큰
        │       ├── token: string
        │       └── platform: 'web'
        └── settings/
            └── notifications/  # 알림 설정
                ├── enabled: boolean
                ├── orderUpdates: boolean
                └── ...
```

### 인덱스 (firestore.indexes.json)

- `orders`: `[userId asc, status asc, createdAt desc]`
- `orders`: `[userId asc, createdAt desc]`
- `deliveryTasks`: `[status asc, updatedAt desc]`
- `deliveryTasks`: `[orderId asc, updatedAt desc]`
