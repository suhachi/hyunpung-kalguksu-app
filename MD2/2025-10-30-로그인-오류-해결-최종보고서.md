# 로그인 오류(auth/invalid-credential) 최종 해결 보고서

작성일: 2025-10-30  
프로젝트: 현풍칼국수 PWA 배달앱  
대상 브랜치: release/v1.0.0

---

## 1) 이슈 개요
- 증상: 로그인 시 `Firebase: Error (auth/invalid-credential)` 표시, Network 400(Bad Request)
- 영향: 관리자/고객 로그인 불가, 운영 콘솔 진입 차단

## 2) 근본 원인(RCA)
- 프런트 Firebase 설정의 Storage 버킷/환경값 불일치
  - `storageBucket`이 `hp-kal.firebasestorage.app`로 지정되어 있었음
  - 표준 Web SDK 구성에서는 버킷 필드에 `{project-id}.appspot.com`을 사용하는 것이 정석
- 일부 문서/코드에 혼재된 버킷 도메인 표기(appspot.com vs firebasestorage.app)가 혼선을 유발

## 3) 조치 내용
- 코드 수정
  - `src/lib/firebase.ts`
    - storageBucket 기본값: `hp-kal.appspot.com`
    - `getStorage(app, 'gs://hp-kal.appspot.com')`로 통일
- Functions 보조 조치
  - `adminSetup` 보강: 기존 사용자여도 비밀번호를 `test1234`로 초기화 가능하도록 업데이트
  - Functions 재배포(Node.js 20, 리전 표준화)
- 문서/체크리스트 정리
  - `MD2/2025-01-30-Auth-로그인-오류-분석보고서.md` 작성
  - 배포/헬스체크 문서에 프로젝트 일치 점검 항목 추가

## 4) 검증(DoD)
- 콘솔 → Users: `aaa@aaa.aaa`, `admin@hp-kal.com` 존재/활성 확인
- Sign-in method: Email/Password Enabled 확인
- Authorized domains: hp-kal.web.app, hp-kal.firebaseapp.com, localhost, 127.0.0.1
- 브라우저 콘솔: `getApp().options.projectId === 'hp-kal'` 확인
- 캐시 초기화(IndexedDB firebaseLocalStorageDb) 후 로그인 재시도 OK (테스트 계정 비밀번호 `test1234`)

## 5) 변경 파일
- `src/lib/firebase.ts`  
  - storageBucket/appspot 경로로 통일
- `src/functions/src/admin/setup.ts`  
  - 기존 사용자 비밀번호 초기화 지원

## 6) 배포/운영
- Functions 재배포 완료(asia-northeast3)  
- 프런트는 빌드/호스팅 재배포 필요 시: `npm run build && firebase deploy --only hosting`

## 7) 재발 방지
- 설정 센터 `/admin/settings`에 프로젝트/도메인 상태 배지 고도화(표준 키 점검)
- 문서의 버킷 표기 일원화: `appspot.com`(필드), `gs://{project-id}.appspot.com`(SDK 경로)
- PR 시 .env 템플릿/런타임 projectId 점검을 체크리스트에 포함
