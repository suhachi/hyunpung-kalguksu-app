## 요약

### 목적
`/admin/settings` 경로에 **설정 센터**를 구현하여 API 키 및 설정의 상태를 진단하고, 서버 비밀키를 안전하게 입력할 수 있는 가이드를 제공합니다.

### 핵심 특징
- ✅ **5개 탭**: 결제/배달/지도/알림/운영
- ✅ **상태 진단**: Functions 연결, 키 존재 여부, 헬스체크
- ✅ **CLI 명령 생성**: 서버 비밀키 설정을 위한 명령 자동 생성
- ✅ **.env 템플릿**: 클라이언트 환경 변수 템플릿 다운로드
- ✅ **배포 스크립트**: Firebase 배포 순서 가이드
- ✅ **보안 강화**: 서버 비밀키는 저장하지 않음

## 주요 기능 상세

### 1. 상태 진단 패널 (공통)

각 탭의 좌측에 상태 진단 패널이 표시됩니다:

**결제 탭**:
- ✅ Functions 연결: Connected/Not set
- ✅ Endpoint: Set/Missing
- ✅ MID: Set/Missing
- ✅ Key: Set/Missing

**배달 탭**:
- ✅ Functions 연결: Connected/Not set
- ✅ Webhook Secret: Set/Missing

**지도 탭**:
- ✅ Kakao Maps API: Set/Missing
- ✅ Google Maps API: Set/Missing

**FCM 탭**:
- ✅ 브라우저 지원: Supported/Not Supported
- ✅ VAPID Key: Set/Missing
- ✅ 알림 권한: Granted/Denied/Default

**운영 탭**:
- ✅ Firestore: Connected/Not Connected
- ✅ Storage: Connected/Not Connected
- ✅ CORS 설정: OK/Check
- ✅ Functions: Connected/Not Connected

### 2. CLI 명령 생성

#### NICEPAY CLI 명령

입력 폼에서 값을 입력하면 실시간으로 CLI 명령이 생성됩니다:

```bash
firebase functions:config:set nicepay.endpoint="https://sandbox-api.nicepay.co.kr" nicepay.mid="YOUR_MID" nicepay.key="YOUR_KEY" nicepay.return_url="https://your-host/pay/return" nicepay.cancel_url="https://your-host/pay/cancel"
```

**특징**:
- 입력한 값은 저장되지 않음 (CLI 생성용으로만 사용)
- 복사 버튼으로 클립보드에 복사
- 확인 명령 버튼 (`firebase functions:config:get`)

#### 배달대행사 CLI 명령

```bash
firebase functions:config:set delivery.secret="webhook_secret" delivery.allowed_ips="1.2.3.4,5.6.7.8"
```

### 3. .env 템플릿 다운로드

`.env 템플릿 다운로드` 버튼을 클릭하면 모든 클라이언트 환경 변수가 포함된 템플릿을 다운로드합니다:

```bash
# Firebase 설정
VITE_FIREBASE_API_KEY=your-api-key
VITE_FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com
# ...

# FCM
VITE_FIREBASE_VAPID_KEY=your-vapid-key

# 지도 API
VITE_KAKAO_MAPS_API_KEY=your-kakao-key
VITE_GOOGLE_MAPS_API_KEY=your-google-key
```

### 4. 배포 스크립트

**운영 탭**에서 배포 스크립트를 복사할 수 있습니다:

```bash
# Firestore 인덱스 및 규칙 배포
firebase deploy --only firestore:indexes,firestore:rules

# Storage Rules 배포
firebase deploy --only storage

# Functions 배포
firebase deploy --only functions

# Frontend 빌드 및 Hosting 배포
npm run build
firebase deploy --only hosting
```

### 5. 배달 설정 CRUD

**배달 탭**에서 비밀키가 아닌 설정을 저장할 수 있습니다:

- 최대 배달 거리 (km)
- 야간 할증 (원)
- 배달비 테이블 (향후 확장)
- 무게 할증 (향후 확장)

**저장 위치**: Firestore `adminSettings/core.delivery`

## 보안 검증

### ✅ 보안 원칙 준수

1. **서버 비밀키는 `functions:config`에만 저장**
   - ✅ 클라이언트에서 비밀키 입력 값 저장하지 않음
   - ✅ UI에서는 "설정됨/미설정" 상태만 표시
   - ✅ 입력한 키 값은 CLI 명령 생성용으로만 사용

2. **헬스체크는 관리자 전용**
   - ✅ `adminHealthCheck` Callable Function
   - ✅ 인증 확인 (`context.auth`)
   - ✅ 관리자 권한 확인 (`role === 'owner' || role === 'admin'`)
   - ✅ 비관리자 호출 시 `permission-denied` 에러 반환

3. **접근 제어**
   - ✅ `/admin/settings` 페이지는 owner/admin만 접근 가능
   - ✅ UI에 Role 배지 표시
   - ✅ 비관리자 접근 시 "접근 권한이 없습니다" 메시지 표시

4. **Firestore Rules**
   - ✅ `adminSettings` 컬렉션은 관리자만 읽기/쓰기 가능
   - ✅ 비밀키는 Firestore에 저장하지 않음

## 사용 가이드

### 1. NICEPAY 설정

1. `/admin/settings` 접속 → "결제" 탭 클릭
2. API Endpoint, MID, Key, Return URL, Cancel URL 입력
3. CLI 명령 미리보기 확인
4. "CLI 복사" 버튼 클릭
5. 터미널에서 복사한 명령 실행
6. "확인 명령" 버튼으로 설정 확인
7. "새로고침" 버튼으로 상태 업데이트

### 2. 배달대행사 설정

1. "배달대행" 탭 클릭
2. Webhook Secret 입력 (허용 IP 목록 선택)
3. CLI 명령 복사 및 실행
4. 배달 설정 저장 (최대 거리, 야간 할증)

### 3. 지도 API 설정

1. "지도/지오코딩" 탭 클릭
2. .env 템플릿 다운로드
3. 프로젝트 루트에 `.env.local` 파일 생성
4. 템플릿 내용 복사 후 실제 API 키로 채움
5. 개발 서버 재시작

### 4. FCM 설정

1. "알림/FCM" 탭 클릭
2. .env 템플릿 다운로드
3. `.env.local`에 `VITE_FIREBASE_VAPID_KEY` 추가
4. "알림 권한 요청" 버튼 클릭
5. 브라우저 알림 권한 허용

### 5. 배포

1. "운영/보안" 탭 클릭
2. "배포 스크립트 복사" 버튼 클릭
3. 터미널에서 순서대로 실행
4. "진단 실행" 버튼으로 상태 확인
