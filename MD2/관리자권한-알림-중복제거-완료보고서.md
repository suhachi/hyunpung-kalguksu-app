## 🔧 권한 체크 플로우 개선

### 개선 전 플로우
```
1. /admin 접속
2. RequireAuth 체크 (인증 확인)
3. RequireAdmin 체크 (role 확인) → role이 아니면 / 리다이렉트
4. AdminLayout.render() 실행
5. AdminLayout.checkAuth() 실행
6. currentUser.role !== 'admin' → 토스트 알림 + / 리다이렉트
```

**문제점**: 단계 3에서 이미 리다이렉트되었는데, 단계 6에서 또 체크하고 알림 표시

### 개선 후 플로우
```
1. /admin 접속
2. RequireAuth 체크 (인증 확인)
3. RequireAdmin 체크 (role 확인) → role이 아니면 / 리다이렉트
4. AdminLayout.render() 실행
5. useEffect에서 로딩만 해제
```

**개선점**: 권한 체크는 `RequireAdmin`에서만 수행, `AdminLayout`은 렌더링만 담당
