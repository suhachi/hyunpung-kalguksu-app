# Firebase Storage 버킷 명시적 지정 적용 완료 보고서

**적용 일시**: 2025-01-29  
**문제**: SDK가 잘못된 버킷(`hp-kal.appspot.com`)으로 요청을 보냄  
**해결**: 모든 Storage 요청을 올바른 버킷(`hp-kal.firebasestorage.app`)으로 통일

---

## ✅ 적용 완료 사항

### 1. `src/lib/firebase.ts` 수정 완료

**변경 사항**:
```typescript
// 변경 전
storageBucket: import.meta.env.VITE_FIREBASE_STORAGE_BUCKET || "your-project.appspot.com",
export const storage = getStorage(app);

// 변경 후
storageBucket: import.meta.env.VITE_FIREBASE_STORAGE_BUCKET || "hp-kal.firebasestorage.app",
export const storage = getStorage(app, "gs://hp-kal.firebasestorage.app");
```

**효과**:
- ✅ `storageBucket` 기본값을 올바른 버킷으로 설정
- ✅ `getStorage()`에 명시적으로 버킷 URL 지정하여 올바른 버킷 사용 보장
- ✅ 환경 변수가 없어도 올바른 버킷 사용

### 2. `src/lib/admin/menuImages.api.ts` 수정 완료

**변경 사항**:
```typescript
// 변경 전
import { getStorage, ref, uploadBytes, ... } from 'firebase/storage';
import { app } from '../firebase';

const storage = getStorage(app); // ❌ 직접 호출

// 변경 후
import { ref, uploadBytes, ... } from 'firebase/storage';
import { storage } from '../firebase'; // ✅ firebase.ts에서 export한 storage 사용

// getStorage(app) 호출 제거
```

**효과**:
- ✅ 모든 업로드/삭제 요청이 `firebase.ts`의 `storage` 인스턴스 사용
- ✅ 버킷 통일 보장
- ✅ `cacheControl` 헤더 추가 (`public,max-age=60`)

### 3. 환경 변수 확인 완료

```bash
VITE_FIREBASE_STORAGE_BUCKET=hp-kal.firebasestorage.app
```

✅ 올바른 버킷 이름으로 설정됨

export async function uploadMenuImage(...) {
  // getStorage(app) 호출 제거
  const objectRef = ref(storage, `menus/${menuId}/${fileName}`);
  
  await uploadBytes(objectRef, processed, {

    cacheControl: 'public,max-age=60', // ✅ 추가
  });
}

## 🎯 기대 효과

### 1. 버킷 통일
- ✅ 모든 Storage 요청이 `hp-kal.firebasestorage.app` 사용
- ✅ 잘못된 버킷(`hp-kal.appspot.com`)으로 요청하지 않음

### 2. CORS 정상 작동
- ✅ CORS가 적용된 올바른 버킷 사용
- ✅ `localhost:3000` origin 허용됨

### 3. 일관성 유지
- ✅ 모든 Storage 관련 코드가 동일한 `storage` 인스턴스 사용
- ✅ 버킷 이름 변경 시 한 곳만 수정하면 됨

## 🔍 검증 방법

### 1. 개발 서버 재시작
```bash

npm run dev
```

### 2. 브라우저 캐시 초기화
- DevTools (F12) → Network → Disable cache 체크
- 하드 리프레시: `Ctrl + Shift + R`

### 3. Network 탭 확인
**성공 시나리오**:
- 요청 URL: `.../v0/b/hp-kal.firebasestorage.app/o?name=menus%2F...` ✅
- OPTIONS 요청 → `200 OK` ✅
- POST/PUT 요청 → `200 OK` 또는 `201 Created` ✅

**실패 시나리오**:
- 요청 URL: `.../v0/b/hp-kal.appspot.com/...` ❌ (여전히 표시되면 환경 변수 재확인)

### 4. 콘솔 오류 확인
- CORS 오류 없음 ✅
- 이미지 업로드 성공 토스트 표시 ✅
