## 개요

배달 대행사 API 연동을 위한 전체 인프라를 구축했습니다. Mock Provider와 실제 Provider(Provider A) 어댑터 패턴으로 설계하여 쉽게 교체/추가 가능하도록 했으며, Firebase Functions로 Webhook 수신 및 Firestore 실시간 동기화를 구현했습니다.

### 주요 기능

- ✅ Provider 선택자 (`getDeliveryProvider()`)
- ✅ Mock Provider (Firestore/localStorage 이중 지원)
- ✅ Provider A 스켈레톤 (실제 API 연동 준비)
- ✅ Firebase Functions Webhook 엔드포인트 (HMAC-SHA256 서명 검증)
- ✅ Firestore 실시간 구독 훅 (`useDeliveryTasks`)
- ✅ 관리자 관제 UI (실시간 업데이트, 필터, 취소 기능)
- ✅ 상태 전이 검증 및 Idempotency

## Firebase Functions Webhook

### 엔드포인트

```
POST https://<region>-<project>.cloudfunctions.net/deliveryWebhook
Headers:
  - Content-Type: application/json
  - x-webhook-signature: <HMAC-SHA256>
Body:
  {
    "type": "task.picked_up",
    "taskId": "task_123",
    "timestamp": 1690000000000,
    "data": {
      "status": "picked_up",
      "eta": 18,
      "location": { "lat": 35.2, "lng": 128.8, "at": 1690000000000 }
    }
  }
```

### 보안 검증

1. **HMAC-SHA256 서명 검증**
   ```typescript
   verifyWebhookSignature(payloadString, signature, secret)
   ```

2. **IP 화이트리스트** (선택)
   ```typescript
   verifyAllowedIP(clientIP)
   ```

3. **Idempotency (중복 방지)**
   ```typescript
   eventId = `${taskId}_${type}_${timestamp}`
   deliveryEvents/{eventId} 문서 존재 확인
   ```

### 이벤트 처리

| 이벤트 타입 | 처리 내용 |
|------------|----------|
| `task.created` | 상태: `created` |
| `task.assigned` | 상태: `assigned` |
| `task.picked_up` | 상태: `picked_up` |

## 상태 전이 표

### 허용된 전이

| 현재 상태 | → | 가능한 다음 상태 |
|----------|---|-----------------|
| `created` | → | `assigned`, `canceled` |
| `assigned` | → | `picked_up`, `canceled` |
| `picked_up` | → | `delivering`, `canceled` |
| `delivering` | → | `completed`, `canceled` |
| `completed` | → | - (전이 불가) |
| `canceled` | → | - (전이 불가) |

### 상태 전이 검증

```typescript
// src/functions/src/delivery/service.ts
const ALLOWED_TRANSITIONS: Record<DeliveryStatus, DeliveryStatus[]> = {
  created: ['assigned', 'canceled'],
  assigned: ['picked_up', 'canceled'],
  picked_up: ['delivering', 'canceled'],
  delivering: ['completed', 'canceled'],
  completed: [],
  canceled: [],
};

function validateStatusTransition(current: DeliveryStatus, newStatus: DeliveryStatus): boolean {
  return ALLOWED_TRANSITIONS[current].includes(newStatus);
}
```
