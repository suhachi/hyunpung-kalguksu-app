```json
{
  "functions": {
    "source": "src/functions",
    "predeploy": ["npm --prefix \"$RESOURCE_DIR\" run build"],

```

```bash

firebase deploy --only functions --region=asia-northeast3
```


## 4. App Check 설정

### 개발 환경: Debug Token

1. Firebase Console → App Check → Apps
2. Web App 선택 → Debug Token 발급
3. `.env.local`에 추가:
   ```
   VITE_APP_CHECK_DEBUG_TOKEN=your-debug-token
   ```

### 운영 환경: reCAPTCHA v3

1. Firebase Console → App Check → Apps → Web App
2. reCAPTCHA v3 활성화
3. 사이트 키 발급받기
4. Hosting HTML에 추가:
   ```html
   <script src="https://www.google.com/recaptcha/api.js"></script>
   ```

### Functions 보호 (App Check 적용)


## 5. NICEPAY URL 매칭 검증

### 설정 확인

```bash
firebase functions:config:get nicepay
```

### URL 검증 스크립트

```bash
#!/bin/bash
PROJECT_DOMAIN="your-project.web.app"
EXPECTED_RETURN="https://${PROJECT_DOMAIN}/pay/return"
EXPECTED_CANCEL="https://${PROJECT_DOMAIN}/pay/cancel"

CONFIG_RETURN=$(firebase functions:config:get nicepay.return_url)
CONFIG_CANCEL=$(firebase functions:config:get nicepay.cancel_url)

if [ "$CONFIG_RETURN" != "$EXPECTED_RETURN" ]; then
  echo "❌ return_url 불일치: $CONFIG_RETURN (예상: $EXPECTED_RETURN)"
  exit 1
fi

if [ "$CONFIG_CANCEL" != "$EXPECTED_CANCEL" ]; then
  echo "❌ cancel_url 불일치: $CONFIG_CANCEL (예상: $EXPECTED_CANCEL)"
  exit 1
fi

echo "✅ NICEPAY URL 매칭 확인 완료"
```

## 7. Firestore TTL 설정

### TTL 필드 추가

```typescript
// Functions에서 초기화 스크립트
import * as admin from 'firebase-admin';

async function setupTTL() {
  const db = admin.firestore();
  
  // idempotency_keys 컬렉션 예시
  const idempotencyDoc = await db.collection('idempotency_keys').doc('example').get();
  if (!idempotencyDoc.exists) {
    await db.collection('idempotency_keys').doc('example').set({
      key: 'example',
      expiresAt: admin.firestore.Timestamp.fromDate(
        new Date(Date.now() + 7 * 24 * 60 * 60 * 1000) // 7일 후
      ),
    });
  }

  // deliveryEvents 컬렉션 예시
  const eventDoc = await db.collection('deliveryEvents').doc('example').get();
  if (!eventDoc.exists) {
    await db.collection('deliveryEvents').doc('example').set({
      taskId: 'example',
      type: 'task.created',
      timestamp: admin.firestore.FieldValue.serverTimestamp(),
      expiresAt: admin.firestore.Timestamp.fromDate(
        new Date(Date.now() + 30 * 24 * 60 * 60 * 1000) // 30일 후
      ),
    });
  }
}
```

### Firestore Console에서 설정

1. Firestore Console → 데이터베이스 → 컬렉션 선택
2. 인덱스 탭 → TTL 필드 선택 (`expiresAt`)
3. TTL 정책 활성화

### 확인

```bash
# TTL 필드가 있는 문서 확인
gcloud firestore documents list --collection-id=idempotency_keys --fields=expiresAt
```

## 8. Cloud Scheduler 설정

### API 활성화

```bash
# Cloud Scheduler API 활성화
gcloud services enable cloudscheduler.googleapis.com

# 또는 Firebase Console → Functions → 설정 → Cloud Scheduler API 활성화
```

### 스케줄 잡 생성 (리전 확인)

```bash
# Functions와 동일한 리전 (asia-northeast3) 사용
gcloud scheduler jobs create http my-scheduled-job \
  --location=asia-northeast3 \
  --schedule="0 4 * * *" \
  --time-zone="Asia/Seoul" \
  --uri="https://asia-northeast3-your-project.cloudfunctions.net/myFunction" \
  --http-method=POST \
  --headers="Authorization=Bearer $(gcloud auth print-access-token)"
```

## 9. OAuth 클라이언트 Redirect URI/JS Origins

### 구글 로그인 사용 시

1. Google Cloud Console → APIs & Services → Credentials
2. OAuth 2.0 클라이언트 ID 선택
3. 승인된 JavaScript 원본에 추가:
   - `https://your-project.web.app`
   - `https://your-project.firebaseapp.com`
   - `http://localhost:5173` (개발 환경)
4. 승인된 리디렉션 URI에 추가:
   - `https://your-project.web.app/__/auth/handler`
   - `http://localhost:5173/__/auth/handler` (개발 환경)

## 10. 에러/성능 모니터링

### Sentry 설정 (Web)

```bash
npm install @sentry/browser @sentry/tracing
```

```typescript
// src/main.tsx
import * as Sentry from '@sentry/browser';
import { BrowserTracing } from '@sentry/tracing';

Sentry.init({
  dsn: import.meta.env.VITE_SENTRY_DSN,
  integrations: [new BrowserTracing()],
  tracesSampleRate: 1.0,
  environment: import.meta.env.MODE,
});
```

### Firebase Crashlytics (Web)

```bash
npm install @firebase/crashlytics
```

```typescript
import { getAnalytics } from 'firebase/analytics';
import { getCrashlytics } from '@firebase/crashlytics';

const crashlytics = getCrashlytics(app);
crashlytics.log('App initialized');
```

### Functions 로그 경고 알림

1. GCP Console → Logging → 알림 생성
2. 로그 필터:
   ```
   resource.type="cloud_function"
   severity>=ERROR
   ```
3. 알림 채널: 이메일/Slack/PagerDuty 연결

### GCP Budget 알림

1. GCP Console → 청구 → 예산 및 알림
2. 예산 생성 → Functions/Storage/Hosting 비용 추적
3. 임계값 설정 (예: 50%, 90%, 100%)
4. 알림 이메일 설정
