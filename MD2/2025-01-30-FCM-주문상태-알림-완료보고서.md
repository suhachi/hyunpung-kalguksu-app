## 개요

FCM (Firebase Cloud Messaging)을 활용한 주문 상태 변경 알림 시스템을 구현했습니다. 주문 상태 변경 시 자동으로 푸시 알림을 전송하고, 딥링크를 통해 해당 주문 상세 페이지로 이동할 수 있습니다.

## 구현 범위

### 1. Firebase Functions (Backend)

#### 1.1 주문 상태 변경 트리거 (`src/functions/src/index.ts`)

- **기능**: Firestore `orders/{orderId}` 문서 업데이트 시 자동으로 FCM 푸시 알림 전송
- **구현 내용**:
  - `onOrderUpdated` 함수를 통해 주문 상태 변경 감지
  - 상태별 알림 템플릿 사용 (`getStatusChangeTitle`, `getStatusChangeMessage`)
  - 딥링크 URL 생성 (`/orders/{orderId}`)
  - `sendPushToUser`를 통한 알림 전송 및 Firestore 기록 저장

```typescript
export const onOrderUpdated = functions.firestore
  .document('orders/{orderId}')
  .onUpdate(async (change, context) => {
    // 상태 변경 감지
    if (before.status === after.status) return;
    
    // 딥링크 URL 생성
    const deepLink = `/orders/${orderId}`;
    
    // FCM 푸시 알림 전송
    await sendPushToUser(after.userId, {
      notification: {
        title,
        body: message,
        icon: '/icons/icon-192x192.png',
        clickAction: deepLink,
      },
      data: {
        type: 'order_status_changed',
        orderId,
        status: String(after.status),
        deepLink,
      },
    });
  });
```

#### 1.2 푸시 알림 유틸리티 (`src/functions/src/lib/push.ts`)

- **`sendPushToUser`**: 개별 사용자에게 푸시 알림 전송
  - FCM 토큰 조회 (`users/{uid}/meta/fcm`)
  - 알림 설정 확인 (`users/{uid}/settings/notifications`)
  - Firestore `notifications` 컬렉션에 알림 기록 저장 (딥링크 포함)

**변경 사항**:
- `deepLink` 필드를 알림 기록에 추가하여 클라이언트에서 딥링크 처리 가능

## 테스트 시나리오

### 1. FCM 토큰 등록

1. 사용자가 앱에 로그인
2. `FCMInitializer`가 자동으로 알림 권한 요청
3. 사용자가 권한 허용
4. FCM 토큰이 `users/{uid}/meta/fcm`에 저장됨

**예상 결과**: 콘솔에 "FCM token obtained" 로그 출력

### 2. 주문 상태 변경 알림

1. 관리자가 주문 상태를 변경 (예: `pending` → `accepted`)
2. `onOrderUpdated` 함수가 트리거됨
3. 사용자에게 푸시 알림 전송
4. Firestore `notifications` 컬렉션에 알림 기록 저장

**예상 결과**:
- 브라우저 알림 표시 (또는 앱 포그라운드 시 Toast)
- `notifications` 컬렉션에 새 문서 생성 (`deepLink` 포함)

### 3. 알림 인박스 확인

1. 사용자가 `/notifications/inbox` 페이지 접속
2. `getNotifications`로 알림 목록 조회
3. 읽지 않은 알림이 강조 표시됨

**예상 결과**:
- 알림 목록 표시
- 읽지 않은 알림 개수 뱃지 표시
- 각 알림에 타입별 아이콘 표시

### 4. 딥링크 이동

1. 사용자가 알림 카드 클릭 (또는 브라우저 알림 클릭)
2. `deepLink` 또는 `data.orderId`를 사용하여 해당 페이지로 이동
3. 알림이 읽음 처리됨

**예상 결과**:
- `/orders/{orderId}` 페이지로 이동
- 알림의 `read` 필드가 `true`로 변경

### 5. 알림 삭제

1. 사용자가 알림 카드의 삭제 버튼 클릭
2. `deleteNotification` 함수 호출
3. Firestore에서 알림 문서 삭제

**예상 결과**:
- 알림이 목록에서 제거됨
- "알림이 삭제되었습니다" Toast 표시

## 주의사항

1. **브라우저 지원**: FCM은 HTTPS 환경에서만 동작합니다. 로컬 개발 시 `localhost`는 예외적으로 허용됩니다.
2. **알림 권한**: 사용자가 알림 권한을 거부한 경우, 푸시 알림은 전송되지만 브라우저 알림은 표시되지 않습니다.
3. **토큰 관리**: FCM 토큰은 브라우저를 변경하거나 앱을 재설치하면 변경될 수 있습니다. 토큰 갱신 로직을 추가하는 것을 권장합니다.
4. **딥링크**: 현재 딥링크는 클라이언트 사이드 라우팅으로 처리됩니다. PWA가 아닌 일반 웹 앱에서는 브라우저 히스토리 API를 사용합니다.
