### 각 기능별 핵심 구현 내용

#### A) 결제 시스템 (NICEPAY)
- Firebase Functions 연동
- Idempotency 키 관리
- HMAC-SHA256 서명 검증
- 4가지 결제 함수 (createPayment, approvePayment, cancelPayment, refundPayment)

#### B) 쿠폰 시스템
- 쿠폰 검증 로직 (최소 금액, 만료일, 사용 여부)
- 체크아웃 페이지 UI 통합
- 주문 시 쿠폰 스냅샷 저장

#### C) 거리 기반 배달비
- 주소 → 좌표 변환 (Geocoding)
- 구간별 배달비 계산 (3,000원 ~ 5,000원)
- 야간 할증 및 불가권역 차단

#### D) 주문 관리
- 주문 목록/상세 페이지
- 필터링 및 무한 스크롤
- 재주문 기능 (가격/재고 경고)

#### E) 이미지 파이프라인
- 자동 WebP 변환
- 썸네일 (640px) 및 리사이즈 (1200px) 생성
- Storage Rules 강화

#### F) FCM 알림
- 주문 상태 변경 시 자동 알림
- 딥링크 지원
- 알림 인박스 페이지

#### G) 배달관제
- Provider 어댑터 패턴
- Webhook 통합 (HMAC-SHA256 검증)
- 실시간 배달 추적
