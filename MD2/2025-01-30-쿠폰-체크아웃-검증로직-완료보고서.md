- ✅ 만료일 검증
- ✅ 사용 여부 검증
- ✅ 중복 사용 방지
- ✅ 실시간 할인 금액 반영

## 구현 내용

### 1. CouponApply 컴포넌트

**위치:** `src/components/checkout/CouponApply.tsx`

**기능:**
- 쿠폰 검색 (제목/설명 검색)
- 사용 가능한 쿠폰 목록 표시
- 최소 주문 금액 미달 쿠폰 표시 (비활성화)
- 쿠폰 적용/해제
- 적용된 쿠폰 정보 표시

**주요 함수:**
```typescript
async function handleApplyCoupon(coupon: Coupon) {
  // 1. 쿠폰 유효성 검증
  const validation = await validateCoupon(coupon.id!, orderAmount, user.uid);
  
  // 2. 검증 실패 시 에러 표시
  if (!validation.valid) {
    toast.error(validation.reason);
    return;
  }
  
  // 3. 쿠폰 적용
  const discountAmount = await applyCouponToCart(coupon.id!, orderAmount, user.uid);
  applyCoupon(coupon.id!, discountAmount, false);
}
```

### 2. 쿠폰 검증 로직

**위치:** `src/lib/coupons.api.ts`

**함수:** `validateCoupon(couponId, orderAmount, uid)`

**검증 항목:**
1. 쿠폰 존재 여부
2. 사용자 소유 확인 (`coupon.uid === uid`)
3. 사용 여부 확인 (`!coupon.used`)
4. 만료일 확인 (`Date.now() <= coupon.expiresAt`)
5. 최소 주문 금액 확인 (`orderAmount >= coupon.minSpend`)

### 3. CartContext 업데이트

**함수:** `applyCoupon(id, discount, validate)`

- `validate=true`일 때 API 검증 수행
- 검증 성공 시 할인 금액 적용
- 실패 시 `false` 반환

**함수:** `canCheckout()`

- 배달/픽업별 최소 주문 금액 체크
- `subtotal >= MIN_ORDER_DELIVERY` (배달) 또는 `MIN_ORDER_PICKUP` (픽업)

### 4. 주문 생성 시 쿠폰 스냅샷 저장

**위치:** `src/pages/app/Checkout.tsx`

**로직:**
```typescript
if (couponId) {
  const usedCoupon = coupons.find(c => c.id === couponId);
  couponSnapshot = {
    id: usedCoupon.id!,
    title: usedCoupon.title,
    amount: usedCoupon.amount,
    minSpend: usedCoupon.minSpend,
    appliedAt: Date.now(),
  };
  
  await useCouponAPI(couponId, orderId);
}
```

주문 문서에 `couponSnapshot` 필드로 저장되어, 나중에 쿠폰 조건이 변경되어도 주문 당시 조건을 보존합니다.

## 테스트 시나리오

### 1. 쿠폰 검색 및 선택

```
1. Checkout 페이지 접속
2. "쿠폰 선택" 버튼 클릭
3. 쿠폰 목록 확인
4. 검색창에 쿠폰 제목 입력 → 필터링 확인
5. 사용 가능한 쿠폰 클릭 → 적용 확인
```

### 2. 최소 주문 금액 검증

```
1. 주문 금액: 5,000원
2. 최소 주문 금액: 10,000원인 쿠폰 선택
3. 결과: "최소 10,000원 이상 주문해야 합니다" 에러
4. 쿠폰 카드에 "불가" 버튼 표시
```

### 3. 만료일 검증

```
1. 만료된 쿠폰 선택 시도
2. 결과: "만료된 쿠폰입니다" 에러
3. 목록에서 제외됨
```

### 4. 중복 사용 방지

```
1. 이미 사용된 쿠폰 선택 시도
2. 결과: "이미 사용된 쿠폰입니다" 에러
```

### 5. 쿠폰 적용 및 할인 반영

```
1. 사용 가능한 쿠폰 선택
2. 할인 금액이 총액에 즉시 반영 확인
3. "쿠폰 할인 -3,000원" 표시 확인
```

### 6. 쿠폰 제거

```
1. 적용된 쿠폰의 X 버튼 클릭
2. 할인 금액이 제거되고 총액 복원 확인
```

### 7. 주문 생성 시 쿠폰 스냅샷 저장

```
1. 쿠폰 적용 후 주문 생성
2. localStorage 또는 Firestore 확인
3. orderData.couponSnapshot 필드 확인:
   - id, title, amount, minSpend, appliedAt 포함
```

### 8. 동시 쿠폰 적용 방지

```
1. 쿠폰 1 적용
2. 쿠폰 2 적용 시도
3. 결과: 쿠폰 1이 자동으로 제거되고 쿠폰 2 적용
   (한 번에 하나의 쿠폰만 적용 가능)
```
