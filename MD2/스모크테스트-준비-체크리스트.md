## 🚨 빠른 트러블슈팅 가이드

### `storage/unauthorized` 에러
- **원인**: Firestore `users/{uid}.role`이 `owner` 또는 `admin`이 아님
- **조치**: 
  1. Firebase Console → Firestore → `users/{uid}` 문서 확인
  2. `role` 필드를 `"owner"` 또는 `"admin"`으로 설정
  3. 재로그인

### Preflight (OPTIONS) 실패
- **원인**: CORS 설정 누락 또는 버킷 이름 불일치
- **조치**:
  1. `gsutil cors get gs://hp-kal.firebasestorage.app` 실행하여 CORS 확인
  2. `cors.json` 파일을 적용: `gsutil cors set cors.json gs://hp-kal.firebasestorage.app`
  3. 대상 버킷: `hp-kal.firebasestorage.app` 확인

### 버킷 불일치
- **원인**: `.env`의 `VITE_FIREBASE_STORAGE_BUCKET` 값 오류
- **조치**:
  1. `.env` 파일에서 `VITE_FIREBASE_STORAGE_BUCKET=hp-kal.firebasestorage.app` 확인
  2. 개발 서버 재시작

### UI 토스트 미노출
- **원인**: `AdminLayout`에서 중복 토스트 처리
- **조치**: 
  - `AdminLayout.tsx`의 `checkAuth()` 함수에서 토스트 제거 확인 (이미 완료 ✅)
