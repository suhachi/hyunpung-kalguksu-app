## 🔧 기술 구현 상세

### Firebase Admin SDK 사용
- Firebase Functions에 이미 `firebase-admin` 설치되어 있음
- 기본 자격 증명(`admin.credential.applicationDefault()`) 사용
- Firestore Rules 우회하여 문서 생성 가능

### 인증 플로우
```
1. 사용자 접근: /admin
2. RequireAuth 체크: onAuthStateChanged
3. 미인증 → /login 리다이렉트 (+ 원래 경로 저장)
4. 로그인 성공 → 원래 경로 또는 /admin 이동
5. RequireAdmin 체크: role === 'admin'
6. 권한 통과 → AdminLayout 렌더링
```

### Storage 업로드 권한
- Storage Rules: `request.auth != null` (인증 필요)
- Firestore에서 `users/{uid}.role` 확인 (클라이언트에서)
- `role: "owner"` 또는 `"admin"` 필요
